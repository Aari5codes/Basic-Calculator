Project Overview:

A simple calculator application built using Python that performs fundamental arithmetic operations.

Features:

1. Addition

2. Subtraction

3. Multiplication

4. Division

5. Error handling (division by zero)

Concepts Used:

1. Functions

2. Conditional statements

3. Arithmetic operators

4. Basic error handling

How to Run:

1. Execute the Python file.

2. Select the desired operation.

3. Enter numbers to perform calculations.

Learning Outcome:

This project reinforced understanding of functions, operators, and structured program design.
